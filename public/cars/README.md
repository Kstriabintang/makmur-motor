# Foto Mobil

Letakkan foto setiap mobil di dalam folder yang sesuai dengan `folderFoto`
pada `lib/data.ts`. Contoh:

```
public/cars/innova-reborn-diesel-2021/1.jpg
public/cars/innova-reborn-diesel-2021/2.jpg
public/cars/innova-reborn-diesel-2021/3.jpg
```

Aturan:

- Format yang didukung: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
- File diurutkan secara natural (`1.jpg`, `2.jpg`, `10.jpg` …) — foto pertama
  dipakai sebagai foto utama kartu & hero.
- Jika folder kosong, website otomatis menampilkan **placeholder gradient
  dengan ikon mobil** — tidak akan error.
