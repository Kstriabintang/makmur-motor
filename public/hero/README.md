# Foto Hero (opsional)

Taruh SATU foto di folder ini untuk dipakai sebagai background banner hero
di halaman utama. Contoh nama: `hero.jpg` (atau `.png` / `.webp`).

- Jika ada file di sini → otomatis dipakai sebagai hero.
- Jika kosong → hero memakai foto mobil unggulan (default).

Rekomendasi: foto mobil studio dengan **latar putih bersih** atau foto
mobil mewah landscape (rasio 16:9 / 16:10), resolusi ≥ 1600px.

## Prompt untuk generate di ChatGPT / DALL·E

> A premium SUV (Toyota Innova / Honda BR-V style) photographed in a
> professional automotive studio, pure clean white seamless background,
> soft even studio lighting with subtle floor reflection, glossy spotless
> paint, dramatic 3/4 front angle, cinematic, ultra-realistic, high
> resolution commercial car photography, no text, no watermark, no people,
> wide landscape composition with empty space on the left for text overlay.

Versi alternatif (latar gelap mewah):

> A luxury car in a dark elegant showroom, dramatic rim lighting, glossy
> reflective black floor, cinematic moody lighting, ultra-realistic,
> commercial automotive photography, wide landscape, empty space on the
> left for text, no text, no people.
